# Seeking Alpha

> Seeking Alpha is a crowd-sourced investment research and analysis platform for stock-market investors, providing breaking financial news, analyst articles, earnings-call transcripts, dividend and quant ratings, stock and ETF screeners, portfolio tracking, and subscription research services. This profile was generated by the API Evangelist enrichment pipeline; Seeking Alpha does not publish a public first-party developer API at this time.
